# WarhammerSlowGrowLeagueMatchups
This is a match up script that utilizes the google api to access a google sheets page. It pairs up players into match ups with regards to previous match ups to ensure that players do not get duplicate games until all players have played against each other at least once. 


You will need to have a google api credentials secret in order to utilize the script. Modify the correct properties in the file in order to run them easily. 

This script was written by me but can be utilized by anyone. Please make use of it to help with your narrative campaigns or help with event pairings.
